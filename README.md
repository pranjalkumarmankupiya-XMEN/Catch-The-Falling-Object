# Catch the Falling Balls

A simple Pygame game where the player moves a basket to catch falling balls.

## Requirements

- Python 3
- Pygame

Install Pygame with:

```bash
pip install pygame
```

## Run the Game

From this project directory, run:

```bash
python main.py
```

## Controls

- **Left Arrow:** Move the basket left
- **Right Arrow:** Move the basket right
- Close the window to exit

## Gameplay

- Catch a falling ball to gain 1 point.
- A missed ball removes 1 life.
- The game ends when all 3 lives are gone.
- Pressing and holding an arrow key continues moving the basket.
